CodeQuest

A coding game with lessons short enough to fit between other things. You read one idea, then type it straight away, earning XP, streaks and badges. No account, no setup, works offline.

01 · The order

What it is.

Stop watching tutorials, type real code and get told straight away whether it's right. Each lesson takes about two minutes: one concept card, then seven hands-on exercises.

You practise five ways: fill in the blank, build the code, put lines in order, find and fix the bug, and type a line. A wrong answer gets a hint. A second miss shows the answer, explains it, and puts the question in a review queue spaced over 1, 3 and 7 days.

Every unit ends with a 10-question boss. Clear a track and its 20-question final exam unlocks; get 17 right and you earn the certificate.

02 · Prep

Two editions: one to type on, one to tap.

Desktop is a Windows app built for a keyboard, with screens styled like the tools you'd use on the job: a three-pane Instructions / Code / Output layout, 1,410 extra write-the-code challenges, and 14 tool tours on mock versions of VS Code, Visual Studio, browser DevTools, Docker Desktop and Windows Terminal.

Mobile is the same lessons on Android, made for one thumb: tap to answer.

Neither needs Docker, .NET or Ollama installed. The editors and terminals are built into the app, and it checks your answers itself.

React 18 · TypeScript · Vite · Electron · Capacitor · Vitest · Playwright · GitHub Actions

  • 7,755 answers that all have to be right. Every exercise's answer is checked against the grader in the test suite, so a lesson can't ship with an answer the app would mark wrong.
  • Played end to end by a script. Scripted browser runs play each lesson, boss and exam from start to finish.
  • Seven technologies, nothing to install. HTML and CSS render in a live preview and the other tracks show the program's output, all inside the app.
  • Every push is a release candidate. A push to main lints, typechecks, tests, builds the Android APK and the Windows .exe, and publishes a release.

04 · On the pass

Released. You can run it today.

CodeQuest is out for 64-bit Windows and Android 7 or newer. The Windows edition runs from a single file with nothing to install. There's no iPhone or Mac version.
